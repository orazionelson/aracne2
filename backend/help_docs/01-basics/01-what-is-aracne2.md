# What is Aracne2?

Aracne2 is a web-based content management system for **scholarly digital
editions**: projects that produce, edit, and publish documents encoded
in TEI XML (Text Encoding Initiative, the academic standard for encoding
historical and literary texts).

Think of it as a specialized word processor and publishing platform built
for philologists, archivists, and digital humanities researchers.

## What it does

- **Organizing** — groups documents into collections (one collection per
  edition or corpus), with shared metadata and permissions.
- **Editing** — lets you author TEI XML directly in the browser, with
  intelligent autocomplete, schema validation, and AI assistance.
- **Workflow** — tracks each collection through draft → assigned →
  review → published, with notifications at every step.
- **Publishing** — turns a collection into a navigable website with
  XSLT-rendered documents, search, indices, and bibliography pages.
- **Exposure** — makes your metadata harvestable by library catalogues
  via OAI-PMH and discoverable by search engines via automatic
  sitemaps.

## What you do not need

Everything happens in the browser. There is nothing to install on your
computer. An editor only needs an account — the administrator takes care
of servers, backups, and configuration.
