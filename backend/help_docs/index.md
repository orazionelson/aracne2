# Welcome to Aracne2 Help

This is the in-app help for editors, designers, and administrators working
on Aracne2. Browse the sections in the sidebar or use the search box above
to jump directly to a topic.

## What you'll find here

- **Basics** — what Aracne2 is, who does what, how to log in.
- **Editing** — collections, documents, the TEI editor, the editorial
  workflow from draft to published, and document version history.
- **Advanced** — facsimile images, bibliography, named entities, AI
  assistance, and natural-language search.
- **Publishing** — the platform's default public pages, dedicated
  websites per collection, standalone search portals, OAI-PMH
  exposure, deposit on external repositories, outbound webhooks,
  email notifications, and per-plugin public links.
- **Reference** — identity providers, the extensions catalog,
  the `aracne` command-line tool for bulk import / export, the
  audit log, the fixity dashboard, the institutional
  policy-pages editor, and your data + GDPR rights.

## Tips

- The left-hand tree mirrors the folders under the help directory — if a
  page looks out of place, it is because a filename needs a numeric prefix
  to pin its sort order.
- The search box is full-text: it searches every help page in one shot
  and returns a short snippet around each hit.
- Looking for a technical reference (database schema, plugin subsystem,
  XQuery API, …)? Those live in the `docs/reference/` folder on disk and
  are deliberately **not** exposed here — this section is for day-to-day
  users.
