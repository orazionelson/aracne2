# Bibliography (Bibliobuilder)

A collection can have one bibliography page that summarises every
source referenced across its documents. This page is generated by the
**Bibliobuilder** — a tool that walks the TEI `<bibl>` elements across
all documents, normalises them, and produces a single clean
`<listBibl>`.

## How it works

1. The Bibliobuilder scans every `<bibl>` / `<biblStruct>` in every
   document of the collection.
2. It deduplicates entries by comparing author, title, and year.
3. It normalises authors into `<persName><surname>…<forename>…</persName>`
   (or `<orgName>` for institutions).
4. It produces a single `<listBibl>` saved as a new **CollectionBibliography
   version**. Every run creates a new version — older versions are kept
   for audit and rollback.

## Accessing the Bibliobuilder

From the collection detail page, click **Bibliobuilder**. The view shows:

- The latest version of the auto-built list.
- A history panel on the right listing every previous run, with the
  option to restore any of them as the current public version.
- A **Rebuild** button that starts a fresh run. AI assistance can be
  turned on to fix common entry formatting mistakes before the list is
  saved.

## Saved bibliographies panel

The collection detail page has a **Saved bibliographies** panel that
shows the currently public version plus the version history. Only one
version at a time can be flagged as public — that is the one the
public website's bibliography page renders.

## Adding external bibliography

For sources not cited in any document but still relevant to the
edition, use the **Zotero Import** plugin (non-native, must be
activated by Admin). It pulls an entire Zotero group library into the
collection's bibliography in one shot, complete with deduplication.

For resolving a single DOI into a clean `<biblStruct>` while editing
a document, use the **DOI** button in the TEI editor (CrossRef Lookup
plugin — also non-native and opt-in).
