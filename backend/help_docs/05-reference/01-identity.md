# Aracne — Catalogo identità

Riferimento compatto per il marchio, le icone e i lockup distribuiti con
la piattaforma. Mirror del preview visuale disponibile come pagina
HTML statica a [`/aracne-icons/preview.html`](/aracne-icons/preview.html).

**5 famiglie**: FA · AI · NM · HZ/TG · VT
**11 sigle** · **42 file**

## Palette

| Nome | Hex | Uso |
|---|---|---|
| Inchiostro | `#131A2A` | Testo e fondi scuri |
| Pergamena | `#ECE2C8` | Fondi caldi |
| Rubrica | `#A62639` | Accenti, titoli |
| Rubrica+ | `#D44A5C` | Hover / stati attivi |

## Font del wordmark

- **Lora Variable 500** (PNG): peso Medium; la `a` centrale di *Aracne* è sempre italic — richiama la distinzione testo-fonte / apparato critico della tradizione filologica.
- **Fraunces** via Google Fonts CDN (SVG): target estetico, stessa famiglia variabile `opsz`, contrasto più alto.
