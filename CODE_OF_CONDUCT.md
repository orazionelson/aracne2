# Code of Conduct

This project adopts the **Contributor Covenant** (version 2.1) as its
code of conduct.

The full text is available at:

- HTML: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Markdown: https://github.com/EthicalSource/contributor_covenant/blob/release/content/version/2/1/code_of_conduct.md

## In short

Participants in this project — issues, pull requests, discussions,
private security reports — are expected to be respectful,
professional, and welcoming to people of every background. Disagreements
about technical decisions are normal; personal attacks, harassment,
discriminatory language, or any other behaviour the Contributor
Covenant marks as unacceptable are not.

## Reporting

Conduct concerns can be reported privately to the maintainer:

**alfredo.cosco@gmail.com**

Reports are handled in confidence. Likely outcomes range from a
private clarification to a temporary or permanent ban from project
spaces, depending on severity and context, following the enforcement
ladder described in the Contributor Covenant.

## Scope

This Code of Conduct applies to all project spaces — the GitHub
repository, its issues and pull requests, any associated discussion
forums, and public spaces when an individual is representing the
project.
